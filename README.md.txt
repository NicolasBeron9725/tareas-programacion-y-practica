# 🚀 CoreLink CRM - Sistema de Gestión Comercial

CoreLink CRM es una solución integral diseñada para optimizar la productividad de equipos de ventas. Permite centralizar la gestión de clientes, monitorear el desempeño de vendedores en tiempo real y automatizar el reparto de bases de datos utilizando un stack tecnológico moderno y seguro.

## 🛠️ Stack Tecnológico
* **Frontend:** HTML5, CSS3 (Inter Font), JavaScript (ES6+).
* **Backend:** Node.js, Express.js.
* **Base de Datos:** PostgreSQL.
* **Seguridad:** Encriptación con Bcrypt y Autenticación con JWT (JSON Web Tokens).

---

## 📋 Funcionalidades Principales

### 👑 Administrador / Supervisor
* **Dashboard de Analítica:** Visualización de ventas totales, ranking de vendedores y salud del embudo (funnel).
* **Acciones Masivas:** Importación de clientes vía CSV y reparto equitativo automático.
* **Control de Equipo:** Monitor de vendedores online y gestión de avisos internos.

### 📞 Vendedor
* **Gestión de Cartera:** Vista filtrada de clientes asignados.
* **Seguimiento:** Historial de notas por cliente para evitar duplicidades.
* **Cierre de Ventas:** Registro rápido de facturación y cambios de estado.
